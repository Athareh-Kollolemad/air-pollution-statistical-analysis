# Air Pollution Statistical Analysis

This repository contains Python-based Jupyter notebooks for statistical analysis of NO<sub>2</sub> and NO air pollution data.

## Introduction

This repository presents a statistical analysis of NO and NO<sub>2</sub> concentration data, combining distribution fitting, and data visualization.

In addition, the repository includes an analysis of the temporal variability of NO<sub>2</sub> concentrations over the entire available dataset period.

## Methodology

The analysis is inspired by and developed based on the methodology used in the following repository:
https://github.com/hurst0415/Spatial-heterogeneity-of-air-pollution-statistics
